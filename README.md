# 🛍️ AI Data Analytics & BI Agent (ระบบผู้ช่วยวิเคราะห์ข้อมูลธุรกิจอัจฉริยะ)

> **"แค่พิมพ์คำถามภาษาไทย AI จะไปค้นฐานข้อมูล สรุปบทวิเคราะห์ให้ผู้บริหารอ่านเข้าใจง่าย พร้อมทำไฟล์ Excel สวยๆ วางไว้บนหน้าจอ Desktop ให้อัตโนมัติ"** 📊✨

---

## 🌟 โปรเจกต์นี้คืออะไร?

เคยไหมที่อยากรู้ข้อมูลยอดขาย ลูกค้า หรือสต็อกสินค้า แต่ต้องรอให้ฝ่ายไอทีเขียนโค้ด SQL ดึงข้อมูลให้?  
ระบบนี้ถูกสร้างขึ้นมาเพื่อให้ **ทุกคนในทีม ไม่ว่าจะเป็นผู้บริหาร ผู้จัดการ หรือฝ่ายการตลาด** สามารถคุยกับฐานข้อมูลได้โดยตรงด้วย **ภาษาไทยธรรมดา**

```text
[ ผู้ใช้พิมพ์ถามภาษาไทย ]
  "ช่วงนี้สินค้าแบรนด์ไหนขายดีที่สุด 5 อันดับแรก"
             │
             ▼
[ 🧠 สมองกล AI ช่วยหาคำตอบ ]
  1. AI ไปดูว่าต้องเปิดดูตารางไหนในฐานข้อมูล
  2. เขียนคำสั่งดึงข้อมูลอย่างปลอดภัย (ดูได้อย่างเดียว ห้ามลบ/ห้ามแก้)
  3. ดึงตัวเลขจริงออกมาคำนวณและวิเคราะห์
             │
             ▼
[ 🎉 สิ่งที่คุณจะได้รับทันที ]
  1. 📊 สรุปประเด็นสำคัญสำหรับผู้บริหาร (Executive Summary)
  2. 🔍 ข้อคิดเห็นและแนวโน้มที่น่าสนใจ (Key Insights)
  3. 🎯 คำแนะนำว่าควรทำอะไรต่อดี (Actionable Steps)
  4. 📑 ไฟล์ Excel สรุปข้อมูลหลายแท็บ พร้อมจัดสีสวยงาม บันทึกลงหน้าจอ Desktop ทันที!
```

---

## ✨ จุดเด่นที่ทำให้ใช้งานง่าย

- 💬 **พิมพ์ภาษาไทยได้ตามธรรมชาติ:** ไม่ต้องรู้โค้ด ไม่ต้องรู้จักคำสั่ง SQL ถามคำถามสั้นๆ หรือถามต่อเนื่องได้เลย
- 📑 **สร้างไฟล์ Excel ให้อัตโนมัติ:** ทุกคำถามที่ดึงข้อมูล ระบบจะแปลงเป็นไฟล์ `.xlsx` ที่มีหัวตารางสวยงาม จัดกลุ่มข้อมูลเป็นสัดส่วน พร้อมเอาไปเสนองานต่อได้ทันที
- 🛡️ **ปลอดภัย สบายใจได้ 100%:** ระบบถูกล็อคให้อ่านข้อมูลได้อย่างเดียว (**Read-Only**) ป้องกันไม่ให้ใครเผลอลบ แก้ไข หรือทำลายข้อมูลในระบบได้เด็ดขาด
- 🔄 **แก้ปัญหาเองได้อัตโนมัติ (Self-Correction):** หาก AI เขียนคำสั่งค้นหาแล้วติดขัด มันจะเรียนรู้จากข้อผิดพลาดและปรับคำสั่งใหม่เองทันที โดยที่คุณไม่ต้องนั่งแก้
- 🤖 **เลือกใช้สมองกล AI ได้ตามใจชอบ:**
  - ⚡ **NVIDIA Cloud (แนะนำ 🌟):** ฉลาด ตอบไวมาก และเข้าใจตรรกะซับซ้อนได้ดีเยี่ยม
  - ☁️ **Google Gemini:** ครบเครื่อง เขียนบทวิเคราะห์ภาษาไทยได้สละสลวย
  - 🖥️ **Local Ollama:** รันบนเครื่องคอมพิวเตอร์ของคุณเอง ใช้งานได้แม้ยามออฟไลน์

## 🚀 เริ่มต้นใช้งานใน 3 ขั้นตอนง่ายๆ

### 1. ติดตั้งโปรแกรมที่จำเป็น
เปิดโปรแกรม Terminal หรือ PowerShell ในโฟลเดอร์โปรเจกต์ แล้วพิมพ์:
```bash
pip install -r requirements.txt
```

### 2. ตั้งค่ารหัสผ่านและ API Key
ก๊อปปี้ไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น `.env` จากนั้นใส่คีย์ที่ต้องการใช้:
```env
# เลือกว่าจะใช้ AI ตัวไหน (nvidia หรือ gemini)
LLM_PROVIDER=nvidia

# ใส่คีย์ของ NVIDIA (ถ้าเลือกใช้ NVIDIA)
NVIDIA_API_KEY=ใส่_API_Key_ของคุณที่นี่
NVIDIA_MODEL=nvidia/nemotron-3.5-lightning-30b-a3b

# ใส่คีย์ของ Google Gemini (ถ้าเลือกใช้ Gemini)
GEMINI_API_KEY=ใส่_Gemini_Key_ของคุณที่นี่

# ข้อมูลเชื่อมต่อฐานข้อมูล MySQL
DB_HOST=127.0.0.1
DB_PORT=3306
DB_NAME=ecommerce_db
DB_USER=ecommerce_reader
DB_PASSWORD=reader_pass123
```

### 3. เปิดหน้าเว็บใช้งานได้เลย!
พิมพ์คำสั่งนี้:
```bash
python -m streamlit run streamlit_app.py
```
เปิดเบราว์เซอร์ไปที่ `http://localhost:8501` หน้าเว็บแชตพร้อมปุ่มตัวอย่างคำถามจะขึ้นมาให้ใช้งานทันที! 🎉

## 🛡️ ปลอดภัย มั่นใจได้

- **ห้ามแก้ไขข้อมูลเด็ดขาด:** ระบบบล็อกคำสั่งทำลายข้อมูล เช่น `DELETE`, `DROP`, `UPDATE` ทุกรูปแบบ หากมีใครพยายามสั่ง ระบบจะปฏิเสธทันที
- **ซ่อนข้อมูลส่วนตัว:** ข้อมูลที่มีความอ่อนไหวสูง เช่น รหัสผ่าน จะถูกกรองออก ไม่นำมาแสดงผลหน้าจอ
- **ตรวจสอบอัตโนมัติ:** มีชุดทดสอบระบบ 31 รายการ ครอบคลุมทั้งความปลอดภัย ความถูกต้องของตัวเลข และการสร้างไฟล์ Excel เพื่อให้มั่นใจได้ว่าระบบทำงานถูกต้องเสมอ 💯
